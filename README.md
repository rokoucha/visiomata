# Visiomata

TV viewer for Android and Android TV

## 特徴

- Mirakurun互換サーバーに接続してTVを再生
- Android TVに対応
- MPEG-2がデコードできない端末でも[mpeg2toh264](https://github.com/otya128/mpeg2toh264)で変換して視聴可能
- [web-bml](https://github.com/otya128/web-bml)でデータ放送に対応
- [libaribcaption](https://github.com/xqq/libaribcaption)で高品質な字幕を表示
